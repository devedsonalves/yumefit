# Yume Fit Mobile

Aplicativo mobile em Expo, React Native e TypeScript.

## Comandos

- `pnpm --filter mobile dev`: inicia o Expo.
- `pnpm --filter mobile android`: abre no Android.
- `pnpm --filter mobile ios`: abre no iOS.
- `pnpm --filter mobile typecheck`: valida TypeScript.
- `pnpm --filter mobile test`: executa testes.

## Ambiente

Copie `.env.example` para `.env` e ajuste `EXPO_PUBLIC_API_BASE_URL`.

Em emulador Android, use `http://10.0.2.2:3000` para acessar uma API rodando no host.
